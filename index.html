// The AI Prompt

Build a Website With One Prompt

Copy this into ChatGPT, Gemini, or any AI assistant — no prior coding needed.

Create a complete single-page blog website using only HTML, CSS, and JavaScript — no frameworks or external libraries. Pages/Sections: 1. A sticky navigation bar with the site name and smooth scroll links (Home, Blog, About, Contact) 2. A hero section with a bold headline, short description, and a "Read Blog" CTA button 3. A blog posts section with 3 article cards — each card has a category tag, title, excerpt, read-time, and "Read more" arrow 4. An About section with a short paragraph and an author blurb 5. A contact section with a simple form (name, email, message + submit button) 6. A minimal footer with the site name, nav links, and a copyright line Design requirements: - Dark theme: deep navy/black (#09090f) background with slightly lighter card surfaces - Accent color: bright cyan (#22d3ee) for headings, links, tags, hover states, and buttons - Font: Google Fonts — Space Grotesk (load via <link>) - Smooth CSS hover transitions on all cards: lift (translateY(-4px)) + glow border - Subtle grid background pattern on the hero using CSS background-image with linear-gradient - Two radial gradient glows (cyan + purple) in the hero for depth - Animated gradient text on the hero headline (—webkit-background-clip: text) - Fully responsive — single column on mobile, multi-column on desktop - Scroll-reveal animation: sections fade up when entering the viewport (use IntersectionObserver) - Animated blinking dot in the hero badge Technical rules: - Single self-contained .html file — all CSS inside <style>, all JS inside <script> - No <img> tags — use CSS gradients and emoji characters for visual interest - Working hamburger menu for mobile that opens/closes the nav - Smooth scroll on all anchor links - All interactive elements have visible :hover and :focus-visible states Output: One complete .html file, ready to open directly in a browser.
